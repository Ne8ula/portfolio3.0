The portfolio runs on a single editorial palette — cream parchment, ink, mauve, and a single muted jade accent. No gradients, no rounded corners, no vermilion. Typography pairs Cormorant Garamond display with JetBrains Mono chrome, letting the serif carry weight and the mono carry data.
